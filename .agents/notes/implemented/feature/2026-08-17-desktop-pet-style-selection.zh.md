# Agent Note: 桌宠风格选择

Status: implemented

[English](2026-08-17-desktop-pet-style-selection.md) | 中文

## 问题

桌宠只有一套全彩女仆插图，用户无法选择成熟御姐黑白女仆装，同时又保留状态专属姿势、动画节奏和像素命中测试。

## 决策

桌面端将 `style` 与 `enabled` 一起持久化到 `pet-settings.json`。它接受 `classic` 和 `black-white-maid`，缺失或无效值回退为 `classic`，且任一偏好改变时保留既有的启用设置。

桌宠右键菜单和系统托盘提供同一组单选风格。选择风格会写入偏好，并立即向渲染页发送消息，替换当前状态姿势的图片。

`black-white-maid` 选择五张独立的透明 PNG：空闲、两个工作姿势、等待审批和拖拽。渲染页为经典和黑白素材建立 alpha 命中缓存，并在状态图片切换时解析当前风格。标题栏按钮使用当前装扮的空闲图。

## 曾考虑的替代方案

**为经典插图套用灰度滤镜。** 不采用：这会让肤色、头发和鲸鱼尾巴都变成灰色，不能呈现黑白女仆服装。

**全部状态共用一张替换图片。** 不采用：工作、等待和拖拽需要不同的动作姿势。

**只在桌宠右键菜单保留选择器。** 不采用：桌宠隐藏时，用户仍需要桌面级入口来查看和选择风格。

## 后果

用户可从任一桌面菜单选择黑白女仆装，选择在重启后仍有效。成熟女仆保留自然肤色、靛紫色头发和鲸鱼尾巴，同时使用黑白制服插图。新增风格需要一项 `PET_STYLE_OPTIONS`、一组状态素材映射和对应的标题栏缩略图。
